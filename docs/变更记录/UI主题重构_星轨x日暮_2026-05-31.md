# UI主题重构：星轨×日暮

**时间**: 2026-05-31

**修改文件**:
- `src/theme.ts` (新建)
- `src/main.tsx`

---

## 根因分析

**问题现象**: Chrona 的 UI 使用固定的 indigo 强调色，卡片是纯色平面设计，视觉上缺乏个性和层次感。

**原因**: 初始 MVP 阶段优先功能实现，样式采用最基础的 CSS 变量 + 平面设计。

---

## 修改详情

### 文件: src/theme.ts (新建)

**AFTER:**
```ts
export type TimePeriod = "dawn" | "morning" | "afternoon" | "evening" | "night" | "late";

export function applyTimeTheme() {
  const theme = getTimeTheme();
  document.documentElement.setAttribute("data-time-period", theme.period);
}
```

> 说明：新增时间感知主题系统，根据当前小时（5-7 凌晨/7-12 早上/12-17 下午/17-20 晚上/20-23 夜晚/23-5 深夜）自动切换 accent 颜色。

### 文件: src/main.tsx (L5-L8)

**BEFORE:**
```tsx
import "./App.css";
```

**AFTER:**
```tsx
import "./App.css";
import { applyTimeTheme } from "./theme";
applyTimeTheme();
```

> 说明：首次渲染前设置 `data-time-period` 属性，避免初始帧使用默认色再跳变。

### 文件: src/App.tsx

**BEFORE:**
```tsx
// 无问候语组件
// logo 使用硬编码颜色 #6366f1 / #8b5cf6
```

**AFTER:**
```tsx
function Greeting() {
  const theme = getTimeTheme();
  const [now, setNow] = useState(formatTimeHM(new Date()));
  useEffect(() => {
    const id = setInterval(() => setNow(formatTimeHM(new Date())), 10000);
    return () => clearInterval(id);
  }, []);
  return (
    <div className="sidebar-greeting">
      <span className="sidebar-greeting-label">{theme.emoji} {theme.label}</span>
      <span className="sidebar-greeting-time">{now}</span>
    </div>
  );
}

// logo gradient 改用 var(--gradient-start) / var(--gradient-end)
// 新增 useEffect 每 5 分钟刷新一次时间主题
```

> 说明：侧边栏新增问候语（如"☀️ 早上好 10:32"），logo 渐变色跟随时间段变化，每 5 分钟自动刷新主题色。

## 解决方案

将原方案一「星轨」（Glassmorphism + 微光质感）与方案三「日暮」（暖色调 + 时间感知主题）合并：

- **星轨**：卡片半透明 + backdrop-filter 毛玻璃、hover 时 accent 色微光边框、数字渐变文字、按钮渐变填充、Tooltip 毛玻璃
- **日暮**：6 个时间段自动切换 accent 颜色（凌晨玫红→早上琥珀→下午橙→晚上紫→深夜靛蓝→凌晨蓝）、侧边栏问候语 + 实时时钟、logo 渐变色跟随变化

所有页面组件（Today/Overview/Timeline/Stats/History/AppMgmt/Settings）无需修改，视觉效果通过全局 CSS 变量 + 类名自动应用。
