# Chrona 需求文档

## 1. 产品概述

本地优先的 Windows 桌面应用，自动追踪当前活跃窗口，生成时间统计与时间线，无需手动操作。

**目标用户**: 希望了解自己时间分配的个人用户。

---

## 2. 核心需求

### 2.1 自动追踪（后台常驻）

- 每隔固定间隔（如 1s）轮询当前前台窗口进程名 + 窗口标题
- 后台静默运行，系统托盘图标驻留
- 支持获取窗口标题以区分浏览器标签页、IDE 文件等细粒度信息
- 最小化到托盘时销毁主窗口以降低内存占用

### 2.2 合并间隔

- 用户可配置"合并间隔"（默认建议 30s）
- 若在间隔内切回同一应用，合并为一条连续记录，避免碎片化

### 2.3 持续记录模式

- 针对特定应用（如视频播放器、音乐播放器）
- 即使无键鼠操作也持续计时，不因空闲而中断

---

## 3. 功能模块

### 3.1 今天页面

| 功能 | 描述 |
|------|------|
| 应用占比图 | 饼图/环形图，按分类或应用展示当日时间占比 |
| 应用时长列表 | 每个应用今日累计使用时长，降序排列 |
| 时间分布图 | 当天 24h 时间轴，展示各时段活跃情况 |

### 3.2 时间线页面（核心）

- 横轴为时间（当天 0:00–24:00），纵轴可选按应用分组
- 每段使用记录渲染为色块，颜色对应应用/分类
- 频繁切换时出现密集分段，直观反映专注度
- 支持悬浮查看详情（应用名、开始/结束时间、时长）

### 3.3 历史页面

- 内置日历组件，点击日期查看该日数据
- 展示内容与"今天页面"一致

### 3.4 数据统计页面

| 功能 | 描述 |
|------|------|
| 趋势图 | 近 7 天 / 近 30 天 / 近一年，各应用时长趋势折线图 |
| 年度热力图 | GitHub 风格，展示每日活跃总时长 |
| 累计排行 | 各应用/分类累计使用时长排行 |

### 3.5 应用管理

- 修改应用显示名称
- 设置应用所属分类
- 自定义应用颜色（用于时间线色块）
- 创建、重命名、删除分类

### 3.6 设置

| 设置项 | 说明 |
|--------|------|
| 合并间隔 | 数值输入，单位秒，默认 30s |
| 持续记录应用列表 | 白名单，指定哪些应用启用持续记录 |
| 主题 | 浅色 / 深色 |
| 语言 | 中文 / English |
| 数据备份 | 导出为文件 |
| 数据恢复 | 从文件导入 |
| 检查更新 | 应用内触发更新检查 |

---

## 4. 非功能需求

| 项目 | 要求 |
|------|------|
| 平台 | Windows 10/11 |
| 数据存储 | 本地优先，无需联网 |
| 内存占用 | 托盘驻留时尽量低（目标 < 50MB） |
| 隐私 | 所有数据仅存本地，不上传 |
| 开机自启 | 可选，默认开启 |

---

## 5. 进阶功能（后续迭代）

- 浏览器标签页标题追踪（需浏览器扩展或 Accessibility API）
- IDE 当前文件名追踪（通过窗口标题解析）
- 应用使用目标设置与提醒
