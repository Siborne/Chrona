# Chrona 页面结构重组设计文档

**日期:** 2026-05-31
**状态:** 已确认

---

## 问题陈述

当前 Chrona 有 7 个页面，存在 3 对功能重叠：

| 页面 A | 页面 B | 重叠点 |
|--------|--------|--------|
| Today（今天） | Overview（总览） | 都是仪表盘 + 排行 + 统计卡片，只是时间粒度不同 |
| Timeline（时间线） | History（历史） | 都是「选日期 → 看那天数据」，只是可视化方式不同 |
| Stats（数据统计） | Overview（总览） | 都有趋势图 + 排行表 |

此外 Today 页面本身过载（6 个区块），导航没有清晰的故事线。

## 目标

将 7 个页面合并为 4 个，消除重叠，每个页面有清晰的职责。

## 新页面结构

### 侧边栏导航（4 项）

| 图标 | 名称 | 职责 |
|------|------|------|
| BarChart3 | 总览 | 今日 + 趋势的仪表盘，Tab 切换时间粒度 |
| CalendarDays | 活动 | 日历选日期 → 时间线 + 应用列表详情 |
| TrendingUp | 统计 | 热力图 + 长期趋势 + 累计排行 |
| Settings | 设置 | 追踪/外观/色彩主题 + 应用管理 + 系统 |

**合并来源：** Today + Overview

### 布局

```

│ │ 今天 │ 7天  │ 14天  │ 30天  │              │
│ └──────┴──────┴───────┴───────┘              │
│                                              │
│ ┌─────────┬─────────┬─────────┐              │
│ │  总时长  │ 活跃应用 │ 会话数  │              │
│ └─────────┴─────────┴─────────┘              │
│                                              │
│ ┌──────────────────┬──────────────────┐      │
│ │ 应用占比(饼图)    │ 分类分布(进度条) │      │
│ └──────────────────┴──────────────────┘      │
│                                              │
│ ┌──────────────────┬──────────────────┐      │

│ └──────────────────┴──────────────────┘      │
│                                              │
│ ┌──────────────────────────────────────┐     │
│ │ 最近会话列表（仅「今天」Tab）         │     │
│ └──────────────────────────────────────┘     │
└──────────────────────────────────────────────┘
```

### Tab 切换逻辑

| Tab | stat 卡片 | 图表区域 | 会话列表 |
|-----|----------|---------|---------|
| 今天 | 选中日期的 total/apps/sessions | 饼图 + 分类 + 24h + 排行 | 显示，有日期翻页 `‹ 今天 ›` |
| 7/14/30天 | 累计/日均/最活跃 | 趋势线图 + 排行表 | 隐藏 |

### Tab 状态行为

- 切换 Tab 时，各 Tab 独立记忆自己的状态（「今天」记住选中日期，「7天」记住天数）
- 从其他 Tab 切回「今天」时，日期重置为今天（不保留之前的翻页状态）
- 默认 Tab：「今天」

### 日期导航

- 「今天」Tab：显示 `‹ [今天 · 2026-05-31] › [今天]` 日期翻页
- 其他 Tab：只显示天数选择器，无日期翻页

### 组件来源

| 区域 | 来源 | 组件 |
|------|------|------|
| 左侧面板 | History | Calendar 组件，有数据的日期显示小圆点 `●` |
| 右侧上方 | Timeline | Gantt 时间线，共享日期 |
| 右侧下方 | History | 应用列表 + 进度条 |

### 交互

- 点击日历日期 → 右侧时间线 + 应用列表同步更新
- 日历支持月份翻页
- Gantt 图的 tooltip 保持现有行为

## 实现影响

### 需要修改的文件

| 文件 | 操作 |
|------|------|
| `src/App.tsx` | NAV_ITEMS 从 7 项改为 4 项，更新 PAGE_COMPONENTS 映射 |
| `src/types/index.ts` | PageId 类型从 7 值改为 4 值 |
| `src/pages/Overview.tsx` | 重写：融合 Today + Overview，增加 Tab 切换 |
| `src/pages/Activity.tsx` | **新建**：融合 Timeline + History |
| `src/pages/Stats.tsx` | 调整布局：热力图提到顶部 |
| `src/pages/Settings.tsx` | 融入 AppMgmt 的组件 |
| `src/pages/Today.tsx` | **删除**（合入 Overview） |
| `src/pages/Timeline.tsx` | **删除**（合入 Activity） |
| `src/pages/History.tsx` | **删除**（合入 Activity） |
| `src/pages/AppMgmt.tsx` | **删除**（合入 Settings） |

### 不需要修改

- Rust 后端（所有 invoke 命令保持不变）
- Store（所有 store action 保持不变）
- 数据库 schema
- 组件（LoadingSpinner, ErrorBanner 等）

### 风险

- **Calendar 组件**当前在 History.tsx 内联定义，需要提取为共享组件或在 Activity.tsx 中重新实现
- **HourlyChart 组件**在 Today.tsx 内联定义，需要保留在 Overview.tsx 中
