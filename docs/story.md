> 一个本地优先的 Windows 桌面应用，自动记录当前正在使用的软件，生成时间统计和时间线。

## 🎯 核心痛点（为什么要做）

- 想知道自己在某个软件/任务上到底花了多少时间
- Steam 计时不够用，案例多了记不住
- Notion 计时模板太慢，手动开始/停止容易忘
- **解决思路**: 后台全自动追踪，不需要手动操作

## ✨ 功能拆解

### 今天页面
- 不同应用分类的占比图
- 每个软件分别用了多久
- 当天不同时间段的时间分布

### 时间线（核心功能）
- 可视化展示什么时间在用什么软件
- 频繁切换软件 → 时间线出现很多分段，一目了然

### 历史页面
- 切换日期查看过去的每日记录
- 内置日历组件，快速跳转

### 数据页面（长期统计）
- 近 7 天 / 近 30 天 / 近一年 的数据趋势
- 近一年 & 每年活跃热力图
- 不同软件的累计时间和使用趋势

### 应用管理
- 修改应用名称、分类、界面颜色
- 创建和管理分类

### 设置
- **合并间隔**: 在该时间内切回同一应用 → 合并为一条时间线
- **持续记录**: 针对有音频播放的应用（如看视频时长时间不操作键鼠也能持续计时）
- 主题切换（浅色/深色）
- 语言设置
- 数据备份恢复
- 软件内检查更新

## 🛠️ 技术选型思考

原项目为开源桌面应用，以下是我自己如果要做时的技术考量：

| 选项          | 判断               |
| ----------- | ---------------- |
| ~~Tauri~~   | ❌ 不适合常驻后台，占内存    |
| **GPUI**    | ✅ 更适合常驻托盘场景      |
| **托盘时销毁窗口** | ✅ 另一种可行方案，减少内存占用 |

### 💡 进阶想法
- 可以获取**进程窗口名** → 拿到浏览器标签页标题、IDE 标签页文件名等更细粒度的信息
- 这样不仅能追踪"在用 Chrome"，还能知道"在看哪个网页"
